자료 정리 프롬프트

```bash
제공하는 강의 자료를 아래 규칙과 구조에 맞춰 정리해 주세요.

1. 문서 구조 및 목차
목차 구성:
문서 시작 부분에 제목과 함께 각 항목으로 이동할 수 있는 하이퍼링크 목차를 작성합니다.
세부 목차는 tab 여백후 '-'와 하이퍼링크를 이용해 작성합니다.

목차 및 헤더 표기법:
목차는 숫자로 순서를 정리하고, 목차에 해당하는 제목은 "##" 헤더를 사용하여 작성하고 이때 형식은 `## 순번. 제목`을 갖습니다.
세부 목차(본문 섹션)는 숫자 없이 "###" 헤더만 사용하여 구분합니다. 

2. 작성 내용 및 범위
포함 요소:
강의 내용 중 주요 개념, 명령어 및 세부 옵션, 단축키를 핵심으로 정리합니다.
자료의 예시는 되도록 생략하되, 특히 자주 사용되는 사용 예제는 표 하단에 별도 섹션으로 추가하여 작성합니다. 해당 자주 사용되는 예제는 "###" 헤더를 사용하고 코드 블록 없이 작성합니다.

제외 요소:
QNA 섹션은 정리에서 제외합니다.
출처 표기([cite: ])는 작성하지 않습니다.

수정 요소:
직접 제작한 강의 자료이므로 오탈자나 잘못된 내용이 일부 포함되어 있을 수 있으니, 이를 확인하고 수정하여 작성합니다.
자료에 작성되어 있는 구체적인 예시나 명사 표현은 일반적인 명사 표현(UserName) 등으로 수정하여 작성합니다.

3. 표 및 상세 작성 규칙
표(Table) 활용:
단축키나 명령어 옵션 등 설명이 필요한 항목은 Markdown 표(| |) 형태로 작성합니다. 표 내부 설명이 길어질 경우 <br>을 사용해 줄바꿈합니다.

4. 서식 및 출력 스타일
출력 형식:
바로 복사해서 사용할 수 있도록 GitHub Markdown(.md) 코드 블록 형태로 출력합니다.
이때 백틱 기호에 의한 충돌이 일어나지 않도록 답변을 제공할때는 백틱 기호를 확장하여 마크 다운 형식으로 답변을 제대로 제공할 수 있도록 확인합니다.

강조 표현: 자주 쓰이거나 중요한 개념 및 용어는 **볼드체**를 사용하여 강조합니다.
톤 앤 매너: 이모티콘 사용은 자제합니다.


```
