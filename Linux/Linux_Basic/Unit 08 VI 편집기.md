## 1. vi 편집기 개요 및 실행

**vi 편집기**는 유닉스 및 리눅스 계열에서 가장 많이 사용되는 **비주얼 에디터(Visual Editor)**입니다. 현재는 다양한 색상과 패턴 검색 등 가시성과 기능이 향상된 **vim(vi improved)**을 주로 사용합니다.

### 실행 명령어 및 옵션

| 명령어 옵션 | 설명 |
| --- | --- |
| `-R` | 파일을 **Readonly** 상태로 오픈<br>여러 사람이 동시에 읽어야 하는 중요 파일에 사용 |
| `-r` | 이전 편집 작업 중 비정상적으로 종료된 파일 **Recovery(복구)** |
| `-L` | 비정상 종료 시 복구 가능한 파일들에 대한 전체 목록 확인 |
| `+<숫자>` | 편집 작업 진입 시 지정한 특정 라인 번호부터 시작 |

**[자주 사용하는 핵심 명령어]**
- `vi`: 새 파일 편집 화면 오픈
- `vi <파일명>`: 지정한 파일명으로 편집 (파일이 없으면 새로 생성)

## 2. vi 편집기 모드 전환

vi 편집기는 크게 3가지 모드로 동작합니다.
*   **명령 모드 (Command Mode)**: 키 입력을 명령어로 해석하여 이동, 삭제, 복사 등을 수행 (기본 모드)
*   **입력 모드 (Input Mode)**: 키 입력을 실제 파일 내용으로 입력
*   **최하위행 모드 (Last Line Mode)**: 화면 맨 아래에서 저장, 종료, 검색, 치환 등의 특정 명령 수행

### 입력 모드 전환키

| 전환키 | 설명 |
| --- | --- |
| `i` | 현재 커서 위치부터 입력 시작 |
| `I` | 현재 커서가 있는 행의 **가장 처음**부터 입력 시작 |
| `a` | 현재 커서 위치 바로 다음부터 입력 시작 |
| `A` | 현재 커서가 있는 행의 **가장 마지막**부터 입력 시작 |
| `o` | 현재 커서가 있는 아래행에 새로운 빈 줄을 만들고 입력 시작 |
| `O` | 현재 커서가 있는 **위행**에 새로운 빈 줄을 만들고 입력 시작 |
| `ESC` | 입력 모드에서 **명령 모드**로 복귀 |

## 3. 명령 모드 Command Mode 핵심 단축키

### 커서 이동

| 단축키 | 설명 |
| --- | --- |
| `w` / `b` | 한 단어 단위로 오른쪽 이동 / 왼쪽 이동 |
| `0` (또는 `^`) / `$` | 현재 라인의 가장 처음으로 이동 / 가장 마지막으로 이동 |
| `<CTRL + F>` / `<CTRL + B>` | 다음 페이지(화면)로 이동 / 이전 페이지로 이동 |
| `H` / `L` | 현재 화면의 가장 첫 번째 줄로 이동 / 가장 마지막 줄로 이동 |
| `1G` / `G` | 문서 전체의 제일 첫 라인으로 이동 / 마지막 라인으로 이동 |

**[자주 사용하는 핵심 이동키]**
- `h`, `j`, `k`, `l`: 각각 좌, 하, 상, 우 방향으로 커서 한 칸 이동

### 삭제 및 교체

| 단축키 | 설명 |
| --- | --- |
| `x` | 현재 커서 위치의 글자 한 개 삭제 |
| `dw` | 현재 커서 위치부터 한 단어 삭제 |
| `dd` | 현재 커서가 있는 전체 라인 삭제 (앞에 숫자를 붙여 여러 줄 삭제 가능) |
| `d0` / `d$` | 현재 커서부터 라인의 처음까지 삭제 / 라인의 마지막까지 삭제 |
| `dG` / `d1G` | 현재 커서 라인부터 문서 마지막까지 삭제 / 문서 처음까지 삭제 |
| `r` / `R` | 현재 글자를 대치 / `<ESC>` 입력 전까지 계속해서 글자 대치 |

### 복사 붙여넣기 및 기타

| 단축키 | 설명 |
| --- | --- |
| `yy` | 현재 커서가 있는 라인 복사, `Y` 로도 사용 가능 (**Yank**) |
| `p` | 현재 커서 위치의 **아랫줄**(또는 뒤)에 복사된 내용 붙여넣기 (**Paste**) |
| `P` | 현재 커서 위치의 **윗줄**(또는 앞)에 복사된 내용 붙여넣기 |
| `u` | 바로 이전에 실행한 상태로 되돌림 (**Undo**) |
| `U` | 라인 전체에 대해 이전 상태로 복구 |
| `<CTRL + r>` | 실행 취소한 것을 다시 실행 (**Redo**) |
| `J` | 현재 라인의 끝에 아래 라인을 끌어올려 하나로 합침 (**Join Line**) |

## 4. 최하위행 모드 Last Line Mode 핵심 명령어

### 저장 및 종료

| 명령어 | 설명 |
| --- | --- |
| `:w` | 현재 내용 저장 |
| `:w <파일명>` | 현재까지의 변경 사항을 지정한 다른 이름으로 저장 |
| `:w!` | 현재 파일에 강제로 저장 (관리자 권한 필요시) |
| `:wq` | 현재 내용 저장 후 편집기 종료 |
| `:wq!` | 현재 파일에 강제로 저장하고 편집기 종료 |
| `:q` | 내용의 변경 사항이 없을 때 편집기 종료 |
| `:q!` | 변경 사항을 무시하고 강제로 편집기 종료 |
| `:r <파일명>` | 지정한 파일의 내용을 현재 커서 위치로 읽어 들임 |
| `:! <명령어>` | vi 편집기를 빠져나가지 않은 상태에서 외부 쉘 명령어 임시 수행 |

### 검색 및 치환

| 명령어 | 설명 |
| --- | --- |
| `n` / `N` | 검색 이후 동일한 단어를 정방향(`n`) 또는 역방향(`N`)으로 계속 찾기 |
| `/<검색어>` | 현재 커서부터 아래쪽 정방향으로 문자열 검색 |
| `?<검색어>` | 문서의 마지막부터 위쪽 역방향으로 문자열 검색 |
| `:%s/<찾을문자열>/<바꿀문자열>/g` | 문서 전체 영역에서 찾을 문자열을 찾아 모두 바꿀 문자열로 치환 |
| `:<시작행>,<끝행>s/<찾을문자열>/<바꿀문자열>/g` | 지정한 시작 라인부터 끝 라인까지만 문자열 치환 적용 |

## 5. vi 편집기 환경 설정

### 주요 환경 변수

vi 편집기의 동작 환경을 변경하기 위해 최하위행 모드에서 `set` 명령어를 사용합니다. 설정을 영구적으로 반영하려면 사용자의 홈 디렉토리에 **환경 설정 파일**을 생성하여 기록해야 합니다.

| 설정 명령어 | 설명 |
| --- | --- |
| `set all` | 현재 편집기에 사용 가능한 모든 기능 변수들의 설정값 전체 표시 |
| `set number` (또는 `nu`) | 화면 좌측에 라인 번호 표시 |
| `set nonumber` (또는 `nonu`) | 화면 좌측 라인 번호 숨기기 |
| `set tabstop=<숫자>` (또는 `ts`) | 파일 내 탭(Tab) 간격 크기 조정 |
| `set autoindent` (또는 `ai`) | 코딩 및 스크립트 작성 시 자동 들여쓰기 기능 활성화 |
| `set shiftwidth=<숫자>` (또는 `sw`) | 자동 들여쓰기 동작 시 적용될 탭 칸 수 설정 |

**[자주 사용하는 핵심 환경설정]**
- `~/.vimrc` (또는 `~/.exrc`): vi 및 vim 편집기 실행 시 항상 적용되도록 설정을 저장해 두는 **개인 환경 설정 파일** (이 파일에 `set` 명령 내용들을 작성하여 저장)
