## 1. 리눅스 파일 시스템 계층 구조

Linux 시스템의 모든 파일은 루트(`/`)가 계층 구조의 최상단에 있는 역전된 단일 디렉토리 트리로 구성된다. 

| 디렉토리 | 목적 |
|---|---|
| **/usr** | 설치된 소프트웨어, 공유 라이브러리가 포함된 파일 및 읽기 전용 프로그램 데이터가 저장된다. |
| **/etc** | 시스템 고유의 구성 파일, OS 부팅시 설정, 보안 설정, 각종 서비스 설정 파일들이 존재한다. |
| **/var** | 재부팅 후에도 유지되는 동적으로 변경되는 파일(데이터베이스, 캐시, 로그파일 등)이 존재한다. |
| **/run** | 마지막 부팅 이후 시작된 프로세스의 런타임 데이터(프로세스 ID 파일, 잠금 파일 등)가 포함되며 재부팅 시 다시 생성된다. |
| **/home** | 일반 사용자의 개인 데이터 및 구성 파일을 저장하는 홈 디렉토리이다. |
| **/root** | **root 사용자**의 홈 디렉토리이다. |
| **/tmp** | 임시 파일용 공간으로, 10일 동안 액세스/변경되지 않은 파일은 자동으로 삭제된다. |
| **/boot** | 부팅 프로세스를 시작하는 데 필요한 파일들이 존재한다. |
| **/dev** | 시스템에서 하드웨어에 액세스하는 데 사용되는 특수 장치 파일을 포함한다. |

## 2. 디렉토리 이동 관련 명령어

### pwd 명령어
* 현재 작업하고 있는 디렉토리의 위치를 **절대경로**를 통해 `/ (root)`부터의 전체 경로로 출력한다.

### cd 명령어
* 작업 디렉토리를 변경하고자 할 때 사용하며, 인자 없이 사용하면 사용자의 **홈 디렉토리**로 이동한다.
* **상대경로(Relative Path)**: 이동하는 기준이 현재 디렉토리이며, 현재 디렉토리를 기준으로 위, 아래로 이동할 때 사용한다.
* **절대경로(Absolute Path)**: 이동하는 기준이 최상위 디렉토리(`/`)이며, root 디렉토리를 기준으로 이동할 때 사용한다.

**[자주 사용되는 경로 지정]**
* `.` : 현재 디렉토리.
* `..` : 상위 디렉토리.
* `~` : 로그인 된 사용자의 홈 디렉토리.
* `-` : 사용한 이전 디렉토리.

## 3. 디렉토리 관리 명령어

### ls 명령어
* 디렉토리에 있는 내용을 확인하고자 할 때 사용한다.

| 옵션 | 설명 |
|---|---|
| **-a** | 모든 파일 표시하며, 숨김 파일(`.`으로 시작하는 파일)도 표시한다. |
| **-l** | 파일 및 디렉토리의 내용을 자세히 보여준다 (파일 종류, 링크 수, 소유자명, 파일 크기 등). |
| **-R** | 해당 디렉토리와 서브디렉토리의 모든 내용을 표시한다. |
| **-F** | 디렉토리인 경우 `/`, 실행 파일인 경우 `*`, 심볼릭 링크는 `@` 표시를 한다. |
| **-i** | 해당 파일의 **inode 번호**를 표시한다. |
| **-n** | 파일의 소유자와 그룹을 숫자로 표시한다. |
| **-d** | 찾고자 하는 디렉토리 자체에 관한 정보만을 표시한다. |
| **-t** | 파일 시간 순으로 정렬한다 (최근 파일이 제일 먼저). |
| **-r** | 정렬 순서를 내림차순으로 역정렬한다. |
| **-h** | 용량을 읽기 쉬운 단위(K, M, G)로 표시한다. |

**[자주 사용되는 명령어]**
* `ls -l` : 현재 디렉토리 안의 목록 정보 자세히 확인.
* `ls -altr` : 숨김 파일 포함, 시간 기반 역순으로 자세히 출력 (로그 파일 확인 시 유용).

### mkdir 명령어
* 새로운 빈 디렉토리를 생성한다.

| 옵션 | 설명 |
|---|---|
| **-m** | 디렉토리의 퍼미션 권한을 지정한다 (기본값: 755). |
| **-p** | 디렉토리 경로로 생성하며, 상위 디렉토리가 없을 시 **상위 디렉토리까지 함께 생성**한다. |

**[자주 사용되는 명령어]**
* `mkdir -p dir3/dir2/dir1` : 상위 디렉토리가 없어도 한 번에 하위 디렉토리까지 생성.

### rmdir 명령어
* **빈 디렉토리**를 삭제하는 명령어이다.

| 옵션 | 설명 |
|---|---|
| **-p** | 하위 항목을 같이 지우며, 상위 경로도 비어있어야 가능하다. |

## 4. 파일 관리 명령어

### touch 명령어
* 파일의 크기가 0인 빈 파일을 생성하거나, 기존 파일의 **수정시간(mtime)**이나 **접근시간(atime)**을 변경한다.

| 옵션 | 설명 |
|---|---|
| **-a** | 최근 파일 사용시간(접근 시간)만 변경한다. |
| **-c** | 파일을 새로 생성하지 않는다. |
| **-d [시간]** | 현재 시간 대신 지정한 시간으로 변경한다. |
| **-m** | 최근 파일 변경 시간(수정 시간)만 변경한다. |
| **-r [파일]** | 현재 시간 대신 지정한 파일의 시간과 동일하게 변경한다. |
| **-t [시간]** | 지정한 시간(MMDDhhmm[[CC]YY][.ss])으로 파일 시간을 임의 변경한다. |

**[자주 사용되는 명령어]**
* `touch -t 08301300 file1` : 파일의 시간을 8월 30일 13시 00분으로 변경.

### cp 명령어
* 파일이나 디렉토리의 내용을 복사하며, 물리적으로 **새로운 inode와 데이터 블록**을 생성한다.

| 옵션 | 설명 |
|---|---|
| **-a** | 원본 파일의 속성, 링크 정보를 그대로 유지하면서 복사한다. |
| **-b** | 대상을 덮어쓰거나 지울 때를 대비해 백업 파일을 만든다. |
| **-f** | 복사할 파일이 존재할 때 강제로 삭제하고 복사한다. |
| **-i** | 복사할 대상이 이미 존재할 경우 덮어쓸 것인지 물어본다. |
| **-p** | 원본 파일의 **소유, 그룹, 권한, 시간 정보를 보존**한 채로 복사한다. |
| **-r, -R** | 디렉토리 복사 시 서브 디렉토리 내에 있는 모든 파일까지 통째로 복사한다. |

**[자주 사용되는 명령어]**
* `cp -r dir1 dir2` : 디렉토리 전체 복사.
* `cp -p file1 file2` : 원본 속성을 유지하며 백업할 때 사용.

### mv 명령어
* 파일이나 디렉토리를 이동하거나 이름을 변경한다. 같은 파티션 내 이동 시 **Inode 정보는 유지**된다.

| 옵션 | 설명 |
|---|---|
| **-b** | 대상을 덮어쓸 때 백업 파일을 생성한다. |
| **-f** | 대상 파일이 이미 있어도 묻지 않고 강제로 옮긴다. |
| **-i** | 대상 파일이 이미 있으면 어떻게 처리할지 물어본다. |
| **-u** | 대상 파일보다 원본 파일이 최신일 때만 복사한다. |
| **-v** | 파일 옮기기 전의 과정을 자세히 보여준다. |

### rm 명령어
* 파일과 디렉토리를 지울 때 사용하며, 복구가 어려우므로 주의해야 한다.

| 옵션 | 설명 |
|---|---|
| **-f** | 삭제할 파일이 없어도 메시지를 띄우지 않고 **강제로 삭제**한다. |
| **-i** | 파일을 삭제할 것인지 일일이 물어본다. |
| **-r, -R** | 하위 경로와 파일을 모두 지우며 디렉토리 삭제 시 필수이다. |
| **-v** | 삭제되는 파일의 정보를 보여준다. |

**[자주 사용되는 명령어]**
* `rm -rf dir1` : 디렉토리와 내부 파일을 묻지 않고 강제로 모두 삭제.

## 5. 파일 내용 확인 명령어

### cat 명령어
* 파일의 내용을 화면에 연속적으로 출력한다.

| 옵션 | 설명 |
|---|---|
| **-n** | 줄번호를 공백을 포함하여 화면 왼쪽에 나타낸다. |
| **-E** | 각 행 끝에 `$` 문자를 출력한다. |
| **-s** | 중복되고 겹치는 빈 행을 하나의 빈 행으로 처리한다. |

### more 명령어
* 큰 파일을 화면 크기(페이지) 단위로 출력한다.

| 옵션 | 설명 |
|---|---|
| **+(숫자)** | 지정한 줄번호부터 출력을 시작한다. |
| **-c** | 위에서부터 한 행씩 지운 후 출력한다 (스크롤하지 않음). |

**[자주 사용되는 명령어]**
* `CMD | more` : 다른 명령어의 긴 출력 결과를 페이지 단위로 확인 (예: `ps -ef | more`).

### head 명령어
* 파일의 처음 시작 부분(기본 10줄)을 출력한다.

| 옵션 | 설명 |
|---|---|
| **-n (숫자)** | 출력할 줄(라인) 수를 지정한다. |
| **-c (숫자)** | 지정된 바이트(Bytes) 수만큼 출력한다. |

### tail 명령어
* 지정된 데이터나 파일의 마지막 부분(기본 10줄)을 보여준다.

| 옵션 | 설명 |
|---|---|
| **-n (숫자)** | 끝에서부터 지정된 수만큼의 줄을 보여준다. |
| **-f** | 파일의 크기가 변할 때마다 **실시간으로 추가된 정보를 출력**한다 (로그 감독 시 유용). |
| **-c (숫자)** | 끝에서부터 지정된 바이트 수만큼 보여준다. |

**[자주 사용되는 명령어]**
* `tail -f /var/log/messages` : 시스템 로그 파일을 실시간으로 모니터링.

## 6. 기타 관리용 명령어

### wc 명령어
* 파일 내의 라인 수, 단어 수, 문자 수(바이트)를 카운트하여 출력한다.

| 옵션 | 설명 |
|---|---|
| **-l** | **라인(Newline) 수**만 출력한다. |
| **-w** | 단어(Word) 수만 출력한다. |
| **-c** | 문자(Byte) 수만 출력한다. |
| **-m** | 캐릭터(Character) 수만 출력한다. |

**[자주 사용되는 명령어]**
* `ps -ef | wc -l` : 실행 중인 프로세스의 개수 수집 등 파이프라인과 결합하여 **데이터 수집(Data Gathering)**에 자주 활용됨.

### su 명령어 (Switching User)
* 로그아웃 없이 다른 사용자의 권한으로 쉘을 실행한다.

| 옵션 | 설명 |
|---|---|
| **-c** | 대화형 쉘을 시작하지 않고, 지정한 **단일 명령**만 수행하도록 한다. |

**[자주 사용되는 명령어 (차이점)]**
* `su [사용자]` : 지정된 사용자로 전환되지만, 이전 사용자의 환경 변수 설정을 그대로 유지한다.
* `su - [사용자]` : 지정된 사용자로 **새로 로그인한 것처럼 동작**하여 사용자 환경 변수(`PATH`, `PS1` 등)를 모두 대상 사용자의 것으로 변경한다.
