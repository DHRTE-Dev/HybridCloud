## 1. 배시쉘 및 로그인/로그아웃

### 주요 개념
* **배시쉘 (bash shell)**: **GNU Bourne-Again Shell**의 약자로, 유닉스 계열의 **Bourne Shell (sh)**을 향상시킨 리눅스 기본 **명령줄 인터프리터 (Command Line Interpreter)**.
* **쉘 프롬프트 (shell prompt)**:
  * 일반 사용자: `user@host:~$` 또는 `[user@host ~]$` (**`$`** 표시)
  * 관리자 (**root**): `root@host:~#` 또는 `[user@host ~]#` (**`#`** 표시)

### 터미널 종류
| 터미널 종류 | 장치 파일 | 설명 |
| --- | --- | --- |
| **물리 콘솔 (Physical Console)** | `/dev/console` | 서버 장비에 직접 연결된 모니터 및 키보드 등 입출력 장치<br>하드웨어 점검, 초기 네트워크 설정, 시스템 복구 용도 |
| **가상 콘솔 (Virtual Console, TTY)** | `/dev/tty1` ~ `/dev/tty6` | 하나의 물리 장치를 통해 여러 독립된 로그인 세션을 소프트웨어적으로 제공<br>`<CTRL + ALT + F1>` ~ `<CTRL + ALT + F6>` 조합으로 전환 |
| **의사 터미널 (Pseudo Terminal, PTY)** | `/dev/pts/0`, `/dev/pts/1` ... | 입력/출력 장치를 시뮬레이션하는 프로그램<br>PuTTY, SecureCRT, Xshell, MovaXterm 등 터미널 에뮬레이터에서 사용 |

## 2. TUI/GUI 환경 전환 및 언어 설정

### 동작 수준 (Runlevel vs Target)
systemd 기반 시스템에서는 기존의 **런레벨 (Runlevel)** 개념이 **타겟 (Target)** 단위로 관리됨.

| 예전 런레벨 | 현재 systemd 타겟 | 설명 |
| --- | --- | --- |
| **0** | **poweroff.target** | 시스템 종료 |
| **1** | **rescue.target** | 로컬 파일 시스템 마운트 및 기본 관리 모드 |
| **3** | **multi-user.target** | 네트워크를 지원하는 비-그래픽 텍스트 모드 (TUI/CLI) |
| **5** | **graphical.target** | 네트워크와 GUI 환경(GNOME 등)을 지원하는 모드 |
| **6** | **reboot.target** | 시스템 재부팅 |

### 언어 설정
* **`LANG` 변수**: 시스템 전역 언어 환경 변수.
* **주요 언어 코드**:
  * 한국어: **`ko_KR.UTF-8`**
  * 영어: **`en_US.UTF-8`**
* **설정 파일**: `/etc/locale.conf`

## 3. 제어문자 및 터미널 단축키

### 프로세스 제어
| 단축키 | 설명 |
| --- | --- |
| **`<CTRL + C>`** | **SIGINT** 신호를 전송하여 실행 중인 프로그램을 강제 종료 |
| **`<CTRL + Z>`** | **SIGTSTP** 신호를 전송하여 현재 프로세스를 일시 정지 (백그라운드 이동) |
| **`<CTRL + \>`** | 프로그램 종료 및 core dump 생성 |
| **`<CTRL + D>`** | **EOF (End of File)** 전달<br>파일의 끝을 알리거나 현재 쉘 세션을 로그아웃/종료 |

### 터미널 입력 편집
| 단축키 | 설명 |
| --- | --- |
| **`<CTRL + A>`** / **`<Home>`** | 커서를 명령행의 맨 처음 위치로 이동 |
| **`<CTRL + E>`** / **`<End>`** | 커서를 명령행의 맨 끝 위치로 이동 |
| **`<CTRL + U>`** | 커서 위치부터 명령행 시작 부분까지 삭제 |
| **`<CTRL + K>`** | 커서 위치부터 명령행 끝 부분까지 삭제 |
| **`<CTRL + W>`** | 커서 앞의 마지막 단어(word) 삭제 |
| **`<ALT + B>`** | 앞 단어의 시작 위치로 이동 |
| **`<ALT + F>`** | 다음 단어의 끝 위치로 이동 |

### 터미널 화면 제어 및 히스토리
| 단축키 | 설명 |
| --- | --- |
| **`<CTRL + L>`** | 화면 지우기 (`clear` 명령어와 동일) |
| **`<CTRL + S>`** | 화면 출력 일시 정지 (Stop) |
| **`<CTRL + Q>`** | 일시 정지된 화면 출력 다시 시작 (Quit pause) |
| **`<CTRL + M>`** | `<Enter>` 키 입력과 동일 (Carriage Return) |
| **`<CTRL + P>`** | 이전 명령어 불러오기 |
| **`<CTRL + N>`** | 다음 명령어 불러오기 |
| **`<CTRL + R>`** | 명령어 히스토리 검색 |

## 4. 운영체제 셧다운 및 재부팅

### 주요 개념
* **셧다운 (Power Off)**: 시스템 전원을 안전하게 종료하는 작업.

## 5. 자주 사용되는 주요 명령어 및 옵션

### SSH 원격 접속 명령어
* **`ssh`**: SSH 프로토콜을 이용해 원격 서버에 접속
  * `ssh <사용자>@<호스트>`: 원격 호스트에 지정한 계정으로 접속
  * `ssh -l <사용자> <호스트>`: `-l` 옵션으로 계정명을 지정하여 접속
  * `ssh -i <인증키_파일> <사용자>@<호스트>`: 공개키 인증 방식 사용 시 비밀키 파일 지정

### Target 및 systemd 제어 명령어
* **`systemctl get-default`**: 부팅 시 적용되는 기본 타겟(Target) 확인
* **`systemctl set-default <타겟명>`**: 다음 부팅부터 적용될 기본 타겟 변경
* **`systemctl isolate <타겟명>`**: 현재 실행 중인 타겟을 즉시 변경
* **`systemctl stop <서비스명>`**: 현재 실행 중인 서비스 즉시 중지
* **`systemctl disable <서비스명>`**: 부팅 시 서비스 자동 실행 비활성화
* **`systemctl disable --now <서비스명>`**: 서비스를 즉시 중지하고 부팅 시 비활성화 설정을 동시에 적용

### 언어 설정 명령어
* **`localectl`**: 현재 시스템의 언어 및 로케일 설정 확인
* **`localectl set-locale LANG=<언어_코드>`**: 시스템 기본 언어를 영구적으로 변경
* **`export LANG=<언어_코드>`**: 현재 터미널 세션의 언어를 임시로 변경

### SELinux 제어 명령어
* **`setenforce 0`**: SELinux 상태를 임시로 **permissive** 모드로 변경
* **`sed -i 's/^SELINUX=enforcing/SELINUX=disabled/' /etc/selinux/config`**: 설정 파일 내 SELinux 동작 모드를 **disabled**로 변경

### 시스템 상태 확인 명령어
* **`who -r`**: 현재 시스템의 동작 수준(Runlevel) 및 변경 시간 확인
* **`exit`**: 현재 쉘 세션 종료 또는 SSH 원격 접속 해제

### 운영체제 전원 및 재부팅 명령어
* **전원 종료**:
  * `poweroff`: 시스템 즉시 종료
  * `init 0`: Runlevel 0으로 전환하여 시스템 종료
  * `shutdown -h now`: `-h`(halt) 옵션을 이용하여 즉시 전원 종료
* **재부팅**:
  * `reboot`: 시스템 즉시 재부팅
  * `init 6`: Runlevel 6으로 전환하여 시스템 재부팅
  * `shutdown -r now`: `-r`(reboot) 옵션을 이용하여 즉시 재부팅
