# 1. 리눅스 명령어 형식

리눅스는 GUI 모드보다는 **TEXT 모드**를 위주로 지향하므로 명령어 사용법 숙지가 필수적입니다.
명령어를 입력하면 **쉘(Shell)**에서 이를 해석하여 작업을 수행하게 됩니다.

| 요소 | 설명 |
|---|---|
| **Command** (명령어) | 실행할 작업의 이름 |
| **Options** (옵션) | 명령어의 동작을 달리 할 때 사용함 <br> 약자 형태를 쓰지 않기 위해서는 **-(double dash)**를 붙임 |
| **Arguments** (인자) | 명령어의 인자 또는 옵션의 인자로 사용됨 <br> 특정 옵션의 인자일 경우 옵션의 위치가 변경될 때 같이 따라다녀야 함 |

**자주 사용되는 명령어 형식**
* `Command [options] [Arguments]`


# 2. 도움말과 암호 변경

### man 명령어 (Manual Pages)
시스템 참고 설명서 인터페이스로, 윈도우의 도움말과 비슷한 역할을 수행합니다.

| 옵션 및 단축키 | 설명 |
|---|---|
| **-k** | 키워드로 매뉴얼 검색 (**apropos**와 동일) |
| **-f** | 명령어에 대한 한 줄 요약 표시 (**whatis**와 동일) |
| **-s** | 특정 섹션 번호로 매뉴얼 검색 |
| **<Enter>** | 다음 줄로 이동 |
| **<Space> / <CTRL + F>** | 다음 페이지로 이동 |
| **<CTRL + B>** | 이전 페이지로 이동 |
| **/** | 단어 검색 <br> (검색 후 **n**: 정방향 다음, **N**: 역방향 이전) |
| **h / q** | 매뉴얼 사용법 확인 (help) / 매뉴얼 빠져나가기 (quit) |

**자주 사용되는 명령어**
* `man -k [검색어]` (에러 발생 시 **mandb** 명령어로 사전 업데이트 필요)
* `man [섹션번호] [명령어/파일]` (동일한 이름의 매뉴얼이 존재할 경우 섹션을 지정하여 검색)

**매뉴얼 섹션 (Manual Section) 구조**
| 섹션 번호 | 설명 및 주요 대상 |
|---|---|
| **Section 1** | 사용자 명령 (실행 가능한 명령 및 쉘 프로그램) <br> 대상: 시스템 관리자 및 일반 사용자 |
| **Section 2** | 시스템 호출 (사용자 공간에서 호출된 커널 루틴) <br> 대상: 개발자 |
| **Section 3** | 라이브러리 기능 (프로그램 라이브러리에서 제공) <br> 대상: 개발자 |
| **Section 4** | 특수 파일 (보통 /dev에 있음) |
| **Section 5** | 파일 형식 및 관례 (운영체제 및 데몬 설정 파일) <br> 대상: 시스템 관리자 |
| **Section 6** | 게임 (오락 프로그램용) |
| **Section 7** | 범례, 표준 및 기타 (프로토콜, 파일시스템) |
| **Section 8** | 시스템 관리 및 권한 명령 (루트 전용 유지 보수 작업) <br> 대상: 시스템 관리자 |
| **Section 9** | 리눅스 커널 API (내부 커널 호출) <br> 대상: 개발자 |

### 기타 도움말 명령어
| 명령어 | 설명 |
|---|---|
| **info / pinfo** | 명령어에 대한 상세 매뉴얼 제공 |
| **whereis** | 명령의 실행 파일, 소스, 매뉴얼 페이지의 위치 찾기 |
| **which** | 사용자의 PATH 환경 변수 내에서 실행 파일의 위치 찾기 |

### passwd 명령어 (암호 변경)
사용자의 인증 토큰(암호)을 업데이트할 때 사용하는 명령어입니다.

| 권한 구분 | 암호 변경 규칙 및 동작 차이 |
|---|---|
| **root 사용자** | 모든 사용자의 암호 변경 가능 <br> 이전 암호를 묻지 않고 바로 새로운 암호로 변경 가능 |
| **일반 사용자** | 자신의 암호만 변경 가능 <br> 이전 암호를 반드시 맞추어야 새로운 암호 입력 가능 |

**일반 사용자 암호 변경 규칙**
* 암호는 8글자 이상이어야 하며, 사용자 이름과 동일할 수 없음.
* 이전 암호와 3글자 이상 달라야 함.
* 2글자의 영문자와 1글자의 숫자 또는 특수 기호가 포함되어야 함.
* 사전 파일에 등록된 단어 및 순서대로 나열된 암호(예: 1234abcd)는 사용할 수 없음.

# 4. 시스템 기본 정보 확인

### uname 명령어
현재 작동 중인 머신과 운영체제 버전에 대한 정보를 출력합니다. 

| 옵션 | 설명 |
|---|---|
| **-a** | 모든 정보 출력 |
| **-s** | 커널 이름 (운영체제 종류) |
| **-r** | 커널 릴리즈 넘버 |
| **-n** | 호스트 이름 (네트워크 노드) |
| **-v** | 커널 버전 |
| **-m** | 머신 하드웨어 타입 (예: x86_64) |
| **-p** | 프로세스 (CPU) 종류 |
| **-i** | 하드웨어 구현 플랫폼 |
| **-o** | 운영체제 종류 |

**자주 사용되는 명령어**
* `uname -a` (커널 릴리즈, 버전, 하드웨어 이름 등 모든 시스템 정보 확인)
* 배포판 버전 확인: `cat /etc/*release` (uname 명령 출력 결과에는 리눅스 배포판 버전에 대한 정보가 없으므로 해당 파일을 통해 확인해야 함)

### date 명령어
시스템 시간과 날짜를 출력하거나 설정합니다. **일반 사용자**는 시간 확인만 가능하며, **root 사용자**는 시간 확인 및 변경이 가능합니다.

| 옵션 및 포맷 | 설명 |
|---|---|
| **-u** | UTC 시간 확인 |
| **-s** | 지정한 시간으로 현재 시간 변경 (예: `-s "2026-12-25"`) |
| **-Iseconds** | ISO 8601 포맷으로 출력 |
| **+%m%d** | 출력 형태 변경 (월/일 출력 형식) |
| **+%Y-%m-%d %H:%M:%S** | 출력 형태 변경 (년-월-일 시:분:초 출력) |

**자주 사용되는 명령어**
* `date +%m%d` 및 `date +%Y%m%d` (웹 로그 파일 이름 형식이나 백업 파일 생성 시 날짜를 동적으로 삽입할 때 널리 사용됨)
* **NTP (Network Time Protocol) 동기화**: 서버의 시간을 동기화하기 위해 **chronyd 서비스(패키지 이름: chrony)**를 사용하며 `/etc/chrony.conf` 파일을 수정하여 원격 타임 서버 목록을 지정할 수 있음.

### cal 명령어
간단한 달력을 출력하는 명령어로, 스케줄러(예: **crontab**)를 설정할 때 특정 날짜와 요일을 확인하기 위해 유용하게 사용됩니다.

| 옵션 및 인자 | 설명 |
|---|---|
| **-j** | 율리우스력(구태양력)으로 출력 |
| **-y** | 현재 년도의 모든 달을 보여줌 |
| **[month] [year]** | 특정 년도의 특정 월 달력을 지정하여 출력 |

**자주 사용되는 명령어**
* `cal` (현재 월의 달력 표시)
* `cal [월] [년도]` (예: `cal 6 2002` - 2002년 6월 달력 출력)
