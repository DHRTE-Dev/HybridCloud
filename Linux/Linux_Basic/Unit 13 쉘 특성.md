## 1. 리다이렉션

### 파일 기술자 (File Descriptor)
**파일 기술자(File Descriptor)**는 프로세스가 파일을 열 때 할당되는 식별 번호로, 기본적으로 예약되어 사용되는 표준 입출력 번호가 존재합니다.

| 파일 기술자 (FD) | 축약 의미 | 설명 |
| :---: | :---: | :--- |
| **0** | **stdin** | **Standard Input (표준 입력)**<br>기본값은 키보드 입력이며 읽기 전용입니다. |
| **1** | **stdout** | **Standard Output (표준 출력)**<br>기본값은 모니터/터미널 출력이며 쓰기 전용입니다. |
| **2** | **stderr** | **Standard Error (표준 에러)**<br>기본값은 모니터/터미널 에러 출력이며 쓰기 전용입니다. |

### 자주 사용되는 예제
mail -s "Test Mail" user01 < /etc/hosts
ls -l /var > ls.txt
./backup.sh > backup.log 2>&1

### 입력 리다이렉션
표준 입력(stdin, 0)의 방향을 변경하여 키보드가 아닌 파일 등 다른 소스로부터 입력을 받는 기능입니다.

| 기호 및 표기 | 설명 |
| :--- | :--- |
| **`<`** 또는 **`0<`** | 표준 입력을 지정된 파일로 재지정합니다. |

### 자주 사용되는 예제
mail -s "Report" admin@example.com < report.txt
wall < /etc/hosts
cpio -t < file.cpio

### 출력 리다이렉션
표준 출력(stdout, 1)의 방향을 변경하여 터미널 화면이 아닌 파일 등으로 결과를 전송합니다.

| 기호 및 표기 | 설명 |
| :--- | :--- |
| **`>`** 또는 **`1>`** | 표준 출력을 파일로 저장합니다. (기존 파일 내용 **덮어쓰기/Overwrite**) |
| **`>>`** 또는 **`1>>`** | 표준 출력을 파일 끝에 추가합니다. (기존 파일 내용 **이어쓰기/Append**) |

### 자주 사용되는 예제
ls -l > lsfile
echo 1111 > filename1
echo 2222 >> filename1

### 에러 리다이렉션
표준 에러(stderr, 2)의 방향을 변경하여 에러 메시지를 별도의 파일로 저장하거나 무시하도록 처리합니다.

| 기호 및 표기 | 설명 |
| :--- | :--- |
| **`2>`** | 표준 에러 메시지를 지정된 파일로 저장합니다. (**덮어쓰기**) |
| **`2>>`** | 표준 에러 메시지를 지정된 파일에 추가합니다. (**이어쓰기**) |
| **`> FILE 2>&1`** 또는 **`&> FILE`** | 표준 출력과 표준 에러를 동일한 파일로 동시 재지정합니다. |
| **`2>/dev/null`** | 발생한 에러 메시지를 버리고 화면에 출력하지 않습니다. |

### 자주 사용되는 예제
ls -l /test/nodir 2> err.log
./configure --prefix=/usr/local/apache2 > apache.log 2>&1
find / -name file1 -type f 2>/dev/null

### Here Document
스크립트 내에서 여러 줄의 문자열을 입력받거나 명령어의 표준 입력으로 여러 줄 데이터를 전달할 때 사용하는 기능입니다.

| 기호 및 표기 | 설명 |
| :--- | :--- |
| **`<< DELIMITER`** | 지정한 구분자(DELIMITER)가 나타날 때까지의 모든 입력 줄을 표준 입력으로 처리합니다. |
| **`<< 'DELIMITER'`** | 작은따옴표로 구분자를 감싸면 내부 변수 해석을 방지합니다. |

### 자주 사용되는 예제
cat << EOF > myfile.txt
hello
linux
EOF

## 2. 파이프

### 파이프의 개념
**파이프(Pipe, `|`)**는 앞서 실행한 명령어의 표준 출력(stdout) 결과값을 뒤에 위치한 명령어의 표준 입력(stdin)값으로 전달하는 기능입니다.

| 기호 | 설명 |
| :---: | :--- |
| **`|`** | 프로세스 간 출력 결과를 커널 버퍼에 저장 후 다음 명령의 입력으로 전달합니다. |

자주 사용되는 예제
ps -ef | more
ps -ef | grep rsyslogd
ls -al | sort -r | more

### tee 명령어
표준 입력으로 받은 내용을 화면(표준 출력)에 보여주는 동시에 지정한 파일에 기록하는 명령어입니다.

| 옵션 / 사용법 | 설명 |
| :--- | :--- |
| **`tee [FILE]`** | 출력 내용을 화면에 표시하면서 파일에 **덮어쓰기**로 저장합니다. |
| **`tee -a [FILE]`** | 출력 내용을 화면에 표시하면서 파일 끝에 **이어쓰기(Append)**합니다. |

### 자주 사용되는 예제
date | tee date.log
echo "$(date): $(ps -ef | grep httpd | wc -l)" | tee -a httpd.cnt
echo WEB | sudo tee /var/www/html/index.html

## 3. 배쉬 쉘 기능

### 쉘 옵션 설정
**`set -o`** 명령어를 사용하여 배쉬 쉘 내부의 다양한 동작 옵션을 활성화(`-o`)하거나 비활성화(`+o`)할 수 있습니다.

| 옵션명 | 기능 및 설명 |
| :--- | :--- |
| **`ignoreeof`** | `<Ctrl+D>` 키 입력으로 인한 갑작스러운 쉘 종료 및 로그아웃을 방지합니다. |
| **`noclobber`** | 출력 리다이렉션(`>`) 시 기존 파일이 존재하면 덮어쓰지 못하도록 제한합니다. |
| **`vi`** | 명령행 편집 모드를 vi 편집기 방식으로 설정합니다. |
| **`emacs`** | 명령행 편집 모드를 emacs 편집기 방식으로 설정합니다 (기본값). |

### 자주 사용되는 예제
set -o ignoreeof
set -o noclobber
set +o noclobber

### 로그아웃 방지 기능
`<Ctrl+D>` 키는 파일의 끝(EOF)을 알리거나 현재 쉘을 종료하는 역할을 합니다. **`ignoreeof`** 옵션을 설정하면 실수로 인한 로그아웃을 막아줍니다.

| 설정 명령어 | 동작 설명 |
| :--- | :--- |
| **`set -o ignoreeof`** | `<Ctrl+D>` 입력 시 쉘이 바로 종료되지 않으며, `exit` 또는 `logout`을 명시해야 종료됩니다. |

### 자주 사용되는 예제
set -o ignoreeof

### 덮어쓰기 방지 기능
기존에 존재하는 중요 파일이 출력 리다이렉션 기호(`>`)에 의해 의도치 않게 삭제되거나 덮어씌워지는 상황을 막아주는 기능입니다.

| 설정 명령어 | 동작 설명 |
| :--- | :--- |
| **`set -o noclobber`** | 이미 존재하는 파일에 대해 `>` 사용 시 에러를 반환하며 덮어쓰기를 차단합니다.<br>단, **`>|`** 기호를 사용하면 이 설정을 강제로 무시하고 덮어쓸 수 있습니다. |

### 자주 사용되는 예제
set -o noclobber
echo "data" >| existing_file

### Tab 자동 완성 기능
명령어나 파일/디렉토리 이름의 일부만 입력한 후 **`<Tab>`** 키를 눌러 나머지 이름을 자동으로 완성하거나 후보 목록을 출력합니다.

| 단축키 / 동작 | 설명 |
| :--- | :--- |
| **`<Tab>`** | 매칭되는 항목이 1개일 때 나머지 문자열을 자동으로 완성합니다. |
| **`<Tab><Tab>`** | 매칭되는 항목이 여러 개일 때 가능한 전체 목록(파일, 명령어, 별칭, 함수 등)을 보여줍니다. |
| **`<Up>/<Down>`** | 이전에 입력했던 명령어 히스토리를 불러와 편집 및 실행합니다. |

### 자주 사용되는 예제
cd /etc/Net<Tab>
cd /etc/sys<Tab><Tab>

## 4. 변수

### 변수의 종류 및 선언
쉘에서 사용되는 변수는 적용 범위와 역할에 따라 **지역 변수**, **환경 변수**, **특수 변수**로 나뉩니다.

| 변수 구분 | 특징 | 선언 / 확인 / 해제 문법 |
| :--- | :--- | :--- |
| **지역 변수 (Local Variable)** | 현재 쉘에서만 유효하며, 서브 쉘(Subshell)에는 전달되지 않습니다. | 선언: **`VAR=value`**<br>확인: **`echo $VAR`**<br>해제: **`unset VAR`** |
| **환경 변수 (Environment Variable)** | 현재 쉘과 하위 서브 쉘 모두에 적용되는 변수입니다. | 선언: **`export VAR=value`** 또는 **`export VAR`**<br>확인: **`env`** 또는 **`echo $VAR`** |
| **변수 확인 명령어** | **`set`**: 모든 변수(지역+환경) 출력<br>**`env`**: 환경 변수만 출력 | - |

### 자주 사용되는 예제
VAR=100
export VAR
unset VAR

### 주요 시스템 및 쉘 환경 변수
쉘 환경의 기본 동작 패턴이나 사용자의 작업 정보를 담고 있는 변수들입니다.

| 환경 변수 | 설명 및 주요 특징 |
| :--- | :--- |
| **`PS1`** | 기본 명령행 프롬프트의 형태를 정의하는 변수입니다. (예: `[\u@\h \W]\$`) |
| **`PS2`** | 명령어가 완결되지 않아 다음 줄로 이어질 때 출력되는 2차 프롬프트입니다. (기본값: `>`) |
| **`PATH`** | 실행 명령어를 검색할 디렉토리 경로 목록으로, 콜론(`:`)으로 구분됩니다. |
| **`HISTTIMEFORMAT`** | `history` 명령어 실행 결과에 시간/날짜 출력 형식을 지정합니다. (예: `"%F %T "`) |
| **`HOME`** | 현재 로그인한 사용자의 홈 디렉토리 경로를 저장합니다. |
| **`PWD`** | 현재 작업 중인 디렉토리의 절대 경로를 나타냅니다. |
| **`LOGNAME` / `USER`** | 현재 로그인한 사용자의 계정명을 저장합니다. |
| **`UID`** | 현재 사용자의 고유 ID 번호를 저장합니다. |
| **`TERM`** | 설정된 터미널 에뮬레이터의 종별 정보를 저장합니다. (예: `xterm-256color`) |
| **`LANG`** | 시스템 설정 언어 및 인코딩 방식을 정의합니다. (예: `ko_KR.UTF-8`) |
| **`SHELL`** | 현재 사용자가 사용 중인 로그인 쉘의 절대 경로를 저장합니다. |

### 자주 사용되는 예제
export PS1='[\u@\h \w]\$ '
export PATH=$PATH:/test
export HISTTIMEFORMAT="%F %T "

### 주요 특수 변수
쉘 실행 환경 상태나 전달된 매개변수를 참조할 수 있도록 미리 예약된 변수입니다.

| 특수 변수 | 설명 |
| :---: | :--- |
| **`$$`** | 현재 동작 중인 쉘 프로세스의 PID(Process ID)를 저장합니다. |
| **`$?`** | 직전에 실행한 명령어의 **종료 상태값(Exit Status)**을 저장합니다. (정상 종료: `0`, 실패/에러: `1~255`) |
| **`$!`** | 최근 백그라운드로 실행된 프로세스의 PID를 저장합니다. |
| **`$0`** | 실행된 스크립트 또는 프로그램의 이름을 저장합니다. |
| **`$1`, `$2`, `$N`** | 스크립트에 전달된 인자(Argument)를 위치별로 참조합니다. |
| **`$*`** | 전달된 위치 인자 전체를 하나의 문자열로 나타냅니다. |
| **`$#`** | 전달된 위치 인자의 총 개수를 저장합니다. |

### 자주 사용되는 예제
echo $$
echo $?
sleep 100 & ; echo $!
./script.sh arg1 arg2

## 5. 메타캐릭터

### 주요 메타캐릭터의 역할
쉘이 특별한 의미로 해석하는 기호들을 **메타캐릭터(Metacharacter)**라고 합니다.

| 메타캐릭터 | 이름 | 설명 및 특이사항 |
| :---: | :--- | :--- |
| **`''`** | **작은따옴표 (Single Quote)** | 내부의 모든 메타캐릭터 및 변수의 특별한 의미를 차단하고 **단순 문자열**로 처리합니다. |
| **`""`** | **큰따옴표 (Double Quote)** | 대부분의 특수문자를 단순 문자열 처리하지만, **`$`**, **`` ` ``**, **`\`**의 의미는 유지하여 해석합니다. |
| **`` ` ``** 또는 **`$()`** | **역따옴표 / 백틱 (Back Quote)** | 내부의 문자열을 **쉘 명령어**로 실행하고 그 결과값으로 대체합니다. |
| **`\`** | **역슬래시 (Backslash)** | **탈출 문자(Escape Character)**로, 바로 뒤에 오는 단일 문자의 특수 의미를 제거합니다. |
| **`;`** | **세미콜론 (Semicolon)** | 한 줄에서 **여러 개의 명령어를 순차적으로 실행**할 때 구문 구분자로 사용합니다. |

### 자주 사용되는 예제
echo '$HOME'
echo "$HOME"
touch server_$(date +%m%d).log
find / -name core -type f -exec rm -f {} \;
date; ls; cal

## 6. 히스토리

### 히스토리 명령어 및 환경 변수
사용자가 입력한 명령어들을 스택(Stack) 메모리 및 파일에 저장하여 재사용할 수 있도록 제공하는 기능입니다.

| 명령어 / 변수 | 구분 | 상세 설명 |
| :--- | :---: | :--- |
| **`history`** | **명령어** | 현재 스택에 기록되어 있는 명령어 목록을 출력합니다. |
| **`history -c`** | **명령어** | 메모리 스택상의 모든 히스토리 기록을 삭제합니다. |
| **`HISTSIZE`** | **환경 변수** | 히스토리 스택 메모리가 보관할 수 있는 최대 명령어 개수입니다. (RedHat 기본값: `1000`) |
| **`HISTFILE`** | **환경 변수** | 히스토리 목록을 영구적으로 저장할 파일 경로입니다. (기본값: `~/.bash_history`) |
| **`HISTFILESIZE`** | **환경 변수** | 히스토리 파일에 저장되는 최대 명령어 개수를 정의합니다. |
| **`HISTTIMEFORMAT`** | **환경 변수** | 히스토리 출력 시 타임스탬프(실행 시간) 표시 형식을 설정합니다. |

### 자주 사용되는 예제
history
history -c
export HISTSIZE=1000

## 7. 엘리어스

### 별칭 설정 및 우선순위
긴 명령어나 자주 사용하는 옵션이 포함된 명령어를 단축어 형태로 정의하여 사용하는 기능입니다.

| 명령어 / 개념 | 구분 | 설명 |
| :--- | :---: | :--- |
| **`alias`** | **목록 / 선언** | 설정된 별칭 목록을 확인하거나 새로운 별칭을 정의합니다. (문법: **`alias 이름='명령어'`**) |
| **`unalias`** | **해제** | 설정된 별칭을 해제합니다. (문법: **`unalias 이름`**) |
| **실행 우선순위** | **우선순위** | 배쉬 쉘에서 명령어를 실행할 때 **`alias > function > builtin > command`** 순으로 우선 적용됩니다. |
| **별칭 무시 실행** | **사용법** | 명령어 앞에 역슬래시(`\`)를 입력하면 별칭을 무시하고 원본 명령어를 직접 실행합니다. (예: `\cp`) |

### 자주 사용되는 예제
alias
alias vi='/usr/bin/vim'
alias ls='ls -h -F --color=auto'
unalias vi

## 8. 환경 파일

### 환경 파일의 종류 및 로드 순서
사용자의 로그인 환경 및 쉘 실행 환경을 초기화하고 정의하기 위해 읽어들이는 환경 설정 파일들입니다.

| 구분 | 환경 파일 경로 | 적용 대상 및 읽히는 시점 |
| :--- | :--- | :--- |
| **전역 (Global)** | **`/etc/profile`** | 모든 사용자에게 적용되며, **로그인 시 1회** 로드됩니다. |
| **전역 (Global)** | **`/etc/profile.d/*.sh`** | `/etc/profile` 및 `/etc/bashrc`에 의해 호출되어 동작하는 개별 설정 스크립트들입니다. |
| **전역 (Global)** | **`/etc/bashrc`** | 모든 사용자에게 적용되며, **새로운 쉘(Subshell)이 실행될 때마다** 로드됩니다. |
| **개인 (User)** | **`~/.bash_profile`** | 개별 사용자 전역 파일로, **로그인 시 1회** 로드됩니다. |
| **개인 (User)** | **`~/.bashrc`** | 개별 사용자 설정 파일로, **새로운 쉘이 실행될 때마다** 로드됩니다. |
| **개인 (User)** | **`~/.bash_logout`** | 개별 사용자가 **로그아웃(종료)할 때** 로드되어 실행됩니다. |

#### 로그인 시 로드 순서 (Login Shell)
`/etc/profile` -> `/etc/profile.d/*.sh` -> `~/.bash_profile` -> `~/.bashrc` -> `/etc/bashrc`

#### 하위 쉘 실행 시 로드 순서 (Non-Login Subshell / Terminal Open)
`~/.bashrc` -> `/etc/bashrc` -> `/etc/profile.d/*.sh`

### 환경 파일별 주요 설정 내용
각 파일의 역할에 따른 권장 설정 항목입니다.

| 파일 항목 | 권장 및 주요 설정 내용 |
| :--- | :--- |
| **전역 환경 파일** | **`PATH`**, **`PS1`**, **`JAVA_HOME`** 등 모든 사용자가 공통으로 필요로 하는 시스템 변수 선언 |
| **개인 환경 파일 (`~/.bashrc`)** | 개별 사용자가 선호하는 개인별 **`alias`**, 개인 맞춤형 **`PATH`** 및 프롬프트 색상/스타일 정의 |

### 자주 사용되는 예제
source ~/.bashrc
vi ~/.bashrc
vi /etc/profile
