## 1. grep 명령어

### 주요 개념 및 정규 표현식
**grep**(Globally / Regular Expression / Print)은 파일 내부 또는 표준 입력 스트림에서 특정 **패턴(Pattern)**을 검색하여 해당 패턴을 포함하는 모든 행을 화면에 출력하는 명령어입니다. 패턴 지정 시 **정규 표현식(Regular Expression)**을 활용하여 유연하고 정밀한 검색이 가능합니다.

주요 **정규 표현식 기호**는 다음과 같습니다:
- **`^`**: 라인의 시작을 의미합니다. (예: `^root` - root로 시작하는 라인)
- **`$`**: 라인의 끝을 의미합니다. (예: `bash$` - bash로 끝나는 라인)
- **`.`**: 임의의 한 문자와 매치됩니다.
- **`*`**: 직전 문자가 0회 이상 반복되는 패턴과 매치됩니다.
- **`[abc]`**: 대괄호 안의 문자 중 임의의 한 문자와 매치됩니다.
- **`[^a]`**: 대괄호 안의 문자를 제외한 나머지 문자와 매치됩니다.

### 명령어 옵션 및 정규식 분류

**grep 정규식 변형 분류 표**

| 변형 명령어 / 옵션 | 명칭 | 설명 |
| --- | --- | --- |
| `-G`, `--basic-regexp` | **BRE** (Basic Regular Expression) | 기본 정규 표현식을 사용합니다 (기본 동작 모드). |
| `-E`, `--extended-regexp` | **ERE** (Extended Regular Expression) | 확장 정규 표현식을 사용합니다. `egrep` 명령어와 동일하게 작동하며 파이프(`\|`), 복수 패턴 지정이 지원됩니다. |
| `-F`, `--fixed-strings` | **Fixed Strings** | 정규 표현식 해석을 수행하지 않고 고정된 문자열 자체로 검색합니다. `fgrep` 명령어와 동일합니다. |
| `-P`, `--perl-regexp` | **PCRE** (Perl-Compatible Regular Expression) | Perl 호환 정규 표현식을 사용하여 한층 더 강력한 패턴 매칭을 제공합니다. |

**grep 주요 옵션 표**

| 옵션 | 명칭 | 설명 |
| --- | --- | --- |
| `-i` | `--ignore-case` | 대소문자를 구분하지 않고 패턴을 검색합니다. |
| `-n` | `--line-number` | 일치하는 라인의 내용과 함께 1부터 시작하는 **행 번호**를 출력합니다. |
| `-l` | `--files-with-matches` | 패턴이 매칭된 파일의 내용 대신 **파일 이름**만 출력합니다. |
| `-v` | `--invert-match` | 지정한 패턴을 포함하지 **않는** 라인만 반대로 출력합니다. |
| `-w` | `--word-regexp` | 단어 단위로 정확히 일치하는 독립된 **단어(Word)** 패턴만 검색합니다. |
| `-c` | `--count` | 매칭된 라인의 내용을 출력하지 않고 일치하는 **라인 수**만 카운트하여 출력합니다. |
| `-r` | `--recursive` | 하위 디렉터리 내부의 모든 파일을 **재귀적**으로 탐색하여 검색합니다. |
| `-A NUM` | `--after-context=NUM` | 패턴이 매칭된 라인과 함께 **이후 NUM 개 라인**을 추가로 출력합니다. |
| `--color[=WHEN]` | `--color` | 검색된 패턴 문자열에 **색상 하이라이트**를 적용합니다. (`never`, `always`, `auto`) |
| `-e PATTERN` | `--regexp=PATTERN` | 하이픈(`-`)으로 시작하는 패턴을 안전하게 전달하거나 복수의 패턴을 지정할 때 사용합니다. |

### 자주 사용되는 실무 예제

대소문자 구분 없이 특정 계정 정보 검색:
grep -i fedora /etc/passwd

라인 번호를 함께 출력하여 특정 설정 항목 위치 확인:
grep -n root /etc/passwd

여러 파일 중 특정 단어가 포함된 파일 목록만 추출:
grep -l root /etc/group /etc/passwd /etc/hosts

완벽하게 독립된 단어로 지정된 프로세스만 명확히 검색:
ps -ef | grep -w rsyslogd

파이프라인 연계 중 grep 명령어 자체 프로세스를 결과에서 제외:
ps -ef | grep rsyslogd | grep -v grep

네트워크 설정 디렉터리 내에서 특정 인터페이스명이 포함된 파일 및 라인 재귀 검색:
grep -r ens160 /etc/

인터페이스 정보 출력 중 매칭 라인 기준 아래 6줄까지 함께 확인:
ip addr | grep -A 6 ens160:

로그 파일에서 다중 에러 키워드(warn, error, fail, crit 등) 동시 탐지 (확장 정규식 사용):
cat /var/log/messages | egrep -i 'warn|error|fail|crit|alert|emerg'

특정 날짜 및 시간대 로그 추적:
cat /var/log/messages | grep 'Aug 28 10:'

## 2. find 명령어

### 주요 개념 및 검색 구조
**find** 명령어는 지정된 디렉토리 계층 구조를 탐색하여 파일 이름, 소유자, 권한, 수정 시간, 파일 크기 등 다양한 **속성 조건**에 일치하는 파일 및 디렉토리를 검색하는 명령어입니다. 

검색된 결과에 대해 단순 출력을 넘어서 삭제(`rm`), 권한 변경(`chmod`), 복사(`cp`) 등 별도의 **연계 명령어 실행**(`-exec`, `-ok`)이 가능합니다.

### 검색 조건 및 옵션

**find 주요 검색 옵션 표**

| 옵션 | 구분 항목 | 설명 |
| --- | --- | --- |
| `-name pattern` | 파일명 검색 | 지정한 파일 이름 또는 특수문자 패턴(`*`, `?`, `[]`)을 기준으로 검색합니다.<br>쉘 확장 방지를 위해 패턴을 작은따옴표로 감쌉니다. |
| `-type c` | 파일 유형 | 파일의 종류를 기준으로 검색합니다.<br>• `f`: 일반 파일 (Regular File)<br>• `d`: 디렉토리 (Directory)<br>• `l`: 심볼릭 링크 (Symbolic Link)<br>• `b`: 블록 장치 (Block Device)<br>• `c`: 문자 장치 (Character Device)<br>• `s`: 소켓 (Socket)<br>• `p`: FIFO 파이프 |
| `-user uname` | 소유자 | 지정한 사용자 이름 또는 UID 소유의 파일을 검색합니다. |
| `-group gname` | 소유 그룹 | 지정한 그룹 이름 또는 GID 소유의 파일을 검색합니다. |
| `-mtime n` | 수정 시간 | 파일 데이터가 마지막으로 수정된 시간(24시간 단위)을 기준으로 검색합니다.<br>• `+n`: n일 초과 (n일 이전)<br>• `-n`: n일 미만 (최근 n일 이내)<br>• `n`: 정확히 n일 전 |
| `-perm mode` | 파일 권한 | 파일 퍼미션을 기준으로 검색합니다.<br>• `mode`: 권한 수치가 정확히 일치하는 파일<br>• `-mode`: 지정된 권한 비트가 최소한 모두 포함된 파일 |
| `-size n[suffix]` | 파일 크기 | 파일 용량을 기준으로 검색합니다. (`+n`: 초과, `-n`: 미만, `n`: 일치)<br>• `c`: Bytes<br>• `k`: Kilobytes<br>• `M`: Megabytes<br>• `G`: Gigabytes<br>• `b`: 512-byte blocks (기본값) |
| `-inum n` | Inode 번호 | 시스템의 특정 Inode 번호와 일치하는 파일을 검색합니다. |
| `-exec command {} \;` | 명령 실행 | 검색된 각 파일에 대해 지정한 명령어를 실행합니다.<br>`{}` 위치에 검색된 파일 경로가 대입되며 `\;`로 종료를 명시합니다. |
| `-ok command {} \;` | 대화형 실행 | `-exec`와 동일하게 작동하지만 명령어 실행 전 사용자에게 승인 여부(`y`/`n`)를 묻습니다. |
| `-ls` | 목록 상세 출력 | 검색된 파일 목록을 `ls -dils` 포맷으로 상세 출력합니다. |

### 자주 사용되는 실무 예제

특정 디렉터리 하위에서 특정 확장자 파일만 검색:
find /usr/share -name '*.xml' -type f

특정 사용자 및 소유 그룹이 지정된 파일의 상세 정보 검색:
find /home -user fedora -group fedora -ls

최근 3일 이내에 수정된 파일 목록 검색:
find . -mtime -3 -type f

수정된 지 3일 이상 경과한 오래된 파일 검색:
find . -mtime +3 -type f

최소 Owner Read(400) 권한 이상을 보유한 파일 탐색:
find . -perm -400 -type f -ls

정확히 특정 바이트 용량을 초과하는 대용량 파일 검색:
find . -size +692252c -type f

30일 이상 지난 오래된 로그 파일 자동 일괄 삭제:
find /Log_Dir -name "*.log" -type f -mtime +30 -exec rm -f {} \;

스케줄러(Crontab)와 연계하여 매일 주기적으로 오래된 로그 삭제 처리:
0 4 * * * find /var/log/app -name "*.log" -type f -mtime +60 -exec rm -f {} \;

디스크 용량 초과(Full) 문제 발생 시 최근 2일 이내에 생성된 1GB 이상 대용량 파일 검색:
find /var -mtime -2 -size +1G -type f

특정 소스 코드 또는 스크립트 파일 내에서 에러 문자열이 포함된 파일 위치 탐색:
find /was -type f -exec grep -l 'Server Error' {} \;

## 3. locate 명령어

### 주요 개념 및 작동 원리
**locate** 명령어는 시스템 전체 실시간 스캔 방식 대신, 미리 생성된 **데이터베이스(mlocate.db)**를 조회하여 파일의 이름이나 경로를 매우 신속하게 검색하는 명령어입니다.

실시간 디렉터리 순회가 없으므로 검색 속도가 월등히 빠르지만, 최근 생성되거나 변경된 파일 정보는 DB가 업데이트되기 전까지 검색되지 않을 수 있습니다. 데이터베이스 최신화를 위해 관리자 권한으로 **`updatedb`** 명령어를 정기적으로 실행해야 합니다.

### 명령어 옵션

**locate 주요 옵션 표**

| 옵션 | 명칭 | 설명 |
| --- | --- | --- |
| `-n NUM` | `--limit NUM` | 검색 결과 중 상위 **NUM 개의 항목**만 제한하여 출력합니다. |
| `-i` | `--ignore-case` | 대소문자를 구분하지 않고 파일 경로를 검색합니다. |
| `-e`, `--existing` | `--existing` | DB 검색 시점에 실제 파일 시스템 상에 **존재하는 파일**만 필터링하여 출력합니다. |

### 자주 사용되는 실무 예제

데이터베이스 수동 즉시 갱신 (관리자 권한 필요):
updatedb

특정 키워드가 포함된 시스템 파일 위치 초고속 검색:
locate passwd

검색 결과 수가 많을 경우 상위 5개 항목만 제한 출력:
locate -n 5 passwd

대소문자 구분 없이 메시지 관련 파일 검색 후 파이프라인으로 출력 제어:
locate -i messages | head

## 4. sed 명령어

### 주요 개념 및 구조
**sed**(Stream Editor)는 원본 파일을 직접 열어서 수정하는 대화형 에디터(vi/vim 등)와 달리, 데이터 스트림 입력으로부터 라인 단위를 순차적으로 읽어 들여 텍스트 **치환, 삭제, 삽입, 추가** 등의 편집 작업을 비대화형으로 처리하는 **스트림 에디터**입니다.

기본 사용 형식:
`sed [옵션] '주소/패턴/하위명령' 파일명`

### 명령어 옵션 및 하위 명령어

**sed 주요 옵션 표**

| 옵션 | 명칭 | 설명 |
| --- | --- | --- |
| `-n` | `--quiet`, `--silent` | 패턴 공간의 자동 출력을 중단하고, `p` 명령으로 명시한 라인만 출력합니다. |
| `-e script` | `--expression` | 실행할 sed 편집 조건식 스크립트를 직접 지정합니다 (다중 조건 지정 가능). |
| `-f script-file` | `--file` | 실행할 sed 명령 구문이 저장되어 있는 스크립트 파일 경로를 지정합니다. |
| `-i[SUFFIX]` | `--in-place` | 편집 결과를 화면에 출력하는 대신 **원본 파일에 즉시 반영(덮어쓰기)**합니다. |

**sed 하위 명령어 표**

| 하위 명령어 | 구분 명칭 | 설명 |
| --- | --- | --- |
| `p` | Print | 지정한 행 또는 패턴과 매칭되는 라인을 출력합니다. |
| `d` | Delete | 지정한 행 또는 패턴과 매칭되는 라인을 삭제합니다. |
| `s` | Substitution | 문자열을 치환합니다. (`s/기존문자열/바꿀문자열/g`) |
| `a` | Append | 지정한 행의 **다음 줄**에 새로운 텍스트 행을 추가합니다. |
| `i` | Insert | 지정한 행의 **이전 줄**에 새로운 텍스트 행을 추가합니다. |

### 자주 사용되는 실무 예제

특정 범위 라인 선택 출력 (1~3번째 라인 출력):
sed -n '1,3p' /etc/hosts

특정 문자열을 포함하는 라인만 선별 출력:
sed -n '/root/p' /etc/passwd

설정 파일 내부의 공백 라인 및 주석(#) 라인 일괄 자동 제거:
sed -i -e '/^$/d' -e '/^#/d' httpd.conf

파일 내부의 특정 단어 치환 및 원본 수정:
sed -i 's/root/ROOT/g' group

SELinux 설정 파일의 동작 모드 치환 (enforcing -> permissive):
sed -i 's/^SELINUX=enforcing/SELINUX=permissive/' /etc/selinux/config

사용자 환경 설정 파일(~/.bashrc)의 맨 마지막 라인 뒤에 신규 단축키(alias) 추가:
sed -i '$a alias c="clear"' ~/.bashrc

특정 라인 지정 추가 및 삽입 (3번째 줄 뒤에 추가 / 1번째 줄 앞에 삽입):
sed -i '3a 3rdLine' file1
sed -i '1i FirstLine' file1

## 5. awk 명령어

### 주요 개념 및 레코드/필드 구조
**awk**(개발자 Aho, Weinberger, Kernighan의 이름 연어)는 구조화된 텍스트 파일이나 출력 데이터 스트림을 레코드(행) 및 필드(열) 단위로 분할하여 **패턴 스캐닝, 필드 추출, 연산 및 데이터 변환**을 수행하는 텍스트 처리 언어입니다.

**레코드 및 필드 변수 구조**:
- **`$0`**: 현재 처리 중인 전체 라인 레코드
- **`$1`, `$2`, `$3`, ...**: 구분자로 분할된 첫 번째, 두 번째, 세 번째 필드 열 데이터

기본 구문 형태:
`awk 'pattern { action }' file`

### 명령어 옵션 및 구문

**awk 주요 옵션 표**

| 옵션 | 명칭 | 설명 |
| --- | --- | --- |
| `-F fs` | `--field-separator` | 입력 필드를 구분할 **구분자(Field Separator)**를 지정합니다 (기본값: 공백 및 탭). |
| `-f script-file` | `--file` | awk 스크립트 프로그램 구문이 저장된 외부 파일 경로를 지정합니다. |
| `-v var=val` | `--assign` | awk 실행 공간 내부에서 사용할 사용자 정의 변수 값을 외부에 지정 및 전달합니다. |

### 자주 사용되는 실무 예제

시스템 사용자 계정 중 일반 사용자 계정(1000 <= UID < 60000) 이름만 추출:
awk -F: '$3 >= 1000 && $3 < 60000 {print $1}' /etc/passwd

마운트된 파일시스템 사용률 퍼센트(%) 수치만 깨끗하게 파싱:
df -h | tail -1 | awk '{print $5}' | awk -F% '{print $1}'

특정 네트워크 카드의 IP 주소 수치만 정확히 필터링:
ip addr show ens160 | grep 'inet ' | awk '{print $2}' | awk -F/ '{print $1}'

시스템 내에 존재 중인 좀비(Zombie) 프로세스 탐지:
ps -elf | awk '$2 == "Z" {print $0}'

출력 컬럼 위치를 원하는 텍스트 문자열과 조합하여 가독성 있게 출력:
awk '{print $1, "is using", $5, "bytes"}' testfile
