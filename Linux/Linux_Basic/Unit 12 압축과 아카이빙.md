## 1. 주요 개념 및 용어 정의

### 압축과 아카이빙의 차이
- **압축(Compress)**: 파일 내 중복 데이터를 제거하거나 효율적인 코드로 변환하여 저장 공간을 줄이는 기술입니다.
- **아카이빙(Archiving)**: 여러 개의 파일이나 디렉토리를 하나의 파일로 묶어서 보관 및 관리하는 기술입니다. 단순히 파일들을 하나로 결합하는 기능이며 용량을 줄이지는 않습니다.

## 2. 단일 파일 압축 명령어

### gzip 및 gunzip
- **알고리즘**: Lempel-Ziv coding (**LZ77**) 사용
- **기본 확장자**: `.gz`
- **특징**: 압축 후 원본 파일의 속성(소유권, 권한, 수정 시간 등)이 유지되며, 원본 파일은 압축 파일로 대체됩니다.

| 옵션 | 설명 |
| --- | --- |
| `-S [suffix]` | 기본 확장자(`.gz`) 대신 지정한 확장자를 사용합니다. |
| `-d` | 압축을 해제합니다 (**gunzip** 명령어와 동일). |
| `-f` | 대상 파일이 이미 존재하더라도 강제로 압축 또는 해제를 수행합니다. |
| `-r` | 디렉토리 지정 시 하위 디렉토리와 파일까지 재귀적으로 각각 압축합니다. |
| `-v` | 압축 및 해제 작업 과정과 압축률을 상세히 출력합니다. |
| `-c` | 결과를 표준 출력(stdout)으로 전달합니다 (**zcat** 및 **gunzip -c**와 함께 내용 확인 시 원본 유지 목적으로 활용). |

### 자주 사용되는 예제
# gzip file1
# gunzip file1.gz
# gzip -d file1.gz
# zcat file1.gz
# gunzip -c file1.gz
# gzip -r dir1
# gunzip -r dir1

### bzip2 및 bunzip2
- **알고리즘**: Burrows-Wheeler 블록 정렬 알고리즘 및 Huffman 코딩 사용
- **기본 확장자**: `.bz2`
- **특징**: **gzip**에 비해 상대적으로 우수한 압축률을 제공합니다. 원본 파일 속성을 보존합니다.

| 옵션 | 설명 |
| --- | --- |
| `-c` | 압축 또는 해제 결과를 표준 출력(stdout)으로 전달합니다. |
| `-d` | 압축을 해제합니다 (**bunzip2** 명령어와 동일). |
| `-z` | 강제로 압축을 수행합니다. |
| `-k` | 압축 또는 해제 시 원본 파일을 삭제하지 않고 보존합니다. |
| `-f` | 덮어쓰기 여부를 묻지 않고 강제로 처리합니다. |
| `-t` | 무결성을 검사하지만 압축을 해제하지는 않습니다. |
| `-q` | 불필요한 경고 메시지를 출력하지 않습니다. |
| `-v` | 압축 비율 등 작업 사항을 상세히 출력합니다. |
| `-1` ~ `-9` | 압축할 때 블록 크기를 100k ~ 900k 단위로 지정합니다. |

### 자주 사용되는 예제
# bzip2 file1
# bunzip2 file1.bz2
# bzip2 -d file1.bz2
# bzcat file1.bz2
# bunzip2 -c file1.bz2
# bzip2 -k file1

### xz 및 unxz
- **특징**: **gzip**, **bzip2** 대비 가장 우수한 압축률을 제공하는 유틸리티입니다.
- **압축률 비교**: **gzip** < **bzip2** < **xz**

| 옵션 | 설명 |
| --- | --- |
| `-c` | 압축 해제 결과를 표준 출력(stdout)으로 전달합니다. |
| `-d` | 압축을 해제합니다 (**unxz** 명령어와 동일). |

### 자주 사용되는 예제
# xz file1
# unxz file1.xz
# xz -d file1.xz
# unxz -c file1.xz

## 3. 아카이빙 및 결합 압축 명령어

### tar 명령어
- **개념**: Tape Archive의 약자로, 여러 개의 파일이나 디렉토리를 하나의 **묶음 파일(.tar)**로 만들거나 백업할 때 사용합니다.
- **구문**: `tar <기능옵션> [공통옵션] <묶음파일명> [대상파일/디렉토리]` (옵션 지정 시 `-` 기호 생략 가능)

| 옵션 | 설명 |
| --- | --- |
| `-c` | 새로운 아카이브(묶음 파일)를 생성합니다. |
| `-x` | 아카이브 파일에서 파일들을 추출(해제)합니다. |
| `-t` | 아카이브 파일의 내용 목록을 확인합니다. |
| `-r` | 기존 아카이브 파일 끝에 새로운 파일을 추가합니다. |
| `-u` | 기존 아카이브 내 파일과 비교하여 최근에 변경된 파일만 추가합니다. |
| `-f` | 사용할 아카이브 파일명을 지정합니다. (반드시 옵션 문자열의 마지막에 배치) |
| `-v` | 처리되는 파일의 진행 과정을 상세히 출력합니다. |
| `-C` | 지정한 디렉토리 경로로 이동하여 압축을 해제합니다. |
| `-z` | **gzip** 알고리즘을 연동하여 아카이빙과 압축/해제를 동시에 수행합니다 (`.tar.gz`, `.tgz`). |
| `-j` | **bzip2** 알고리즘을 연동하여 아카이빙과 압축/해제를 동시에 수행합니다 (`.tar.bz2`, `.tbz`). |
| `-J` | **xz** 알고리즘을 연동하여 아카이빙과 압축/해제를 동시에 수행합니다 (`.tar.xz`, `.txz`). |

### 자주 사용되는 예제
# tar cvf file.tar file1 file2 file3
# tar tvf file.tar
# tar xvf file.tar
# tar cvzf file.tar.gz file1 file2 file3
# tar tvzf file.tar.gz
# tar xvzf file.tar.gz
# tar cvjf file.tar.bz2 file1 file2 file3
# tar tvjf file.tar.bz2
# tar xvjf file.tar.bz2
# tar cvJf file.tar.xz file1 file2 file3
# tar tvJf file.tar.xz
# tar xvJf file.tar.xz

### zip 및 unzip
- **개념**: **Linux**와 **Windows** 등 다양한 OS 환경 간 높은 호환성을 제공하는 압축/아카이빙 유틸리티입니다.
- **특징**: 별도의 타르볼(tar) 과정 없이 여러 파일 및 디렉토리를 직접 하나의 압축 파일(`.zip`)로 생성합니다.

| 옵션 | 설명 |
| --- | --- |
| `zip -r` | 디렉토리를 포함하여 하위 파일까지 재귀적으로 압축합니다. |
| `unzip -l` | 압축 해제 없이 **zip** 파일 내부 목록 및 정보를 확인합니다. |

### 자주 사용되는 예제
# zip file.zip file1 file2 file3
# zip -r all.zip doc/
# unzip -l file.zip
# unzip file.zip

### 기타 아카이빙 유틸리티

| 유틸리티 | 설명 |
| --- | --- |
| **cpio** | 표준 입출력을 이용하여 아카이브를 생성 및 해제하는 도구입니다.<br>주로 `find` 명령어와 함께 조합하여 사용합니다. |
| **jar** | Java Archive 형식으로, 내부적으로 **zip** 압축 알고리즘을 사용하는 아카이빙 도구입니다. |

### 자주 사용되는 예제
# find . -name "file*" | cpio -ocv > file.cpio
# cpio -itv < file.cpio
# cpio -iv < file.cpio
# jar cvf file.jar file1 file2
# jar tvf file.jar
# jar xvf file.jar

## 4. 압축 파일 확장자별 주요 특징

| 확장자 | 압축/아카이빙 도구 | 설명 |
| --- | --- | --- |
| `.gz` | **gzip** | Linux/Unix 환경의 표준 단일 파일 압축 형식입니다. |
| `.bz2` | **bzip2** | **gzip** 대비 우수한 압축률을 제공하는 단일 파일 압축 형식입니다. |
| `.xz` | **xz** | 고성능 압축 유틸리티로 가장 높은 압축률을 제공합니다. |
| `.tar` | **tar** | 여러 파일/디렉토리를 묶은 아카이브 파일입니다 (압축 미적용). |
| `.tar.gz` / `.tgz` | **tar** + **gzip** | **tar** 아카이브를 **gzip**으로 압축한 결합 파일 형식입니다. |
| `.tar.bz2` / `.tbz` | **tar** + **bzip2** | **tar** 아카이브를 **bzip2**로 압축한 결합 파일 형식입니다. |
| `.tar.xz` / `.txz` | **tar** + **xz** | **tar** 아카이브를 **xz**로 압축한 결합 파일 형식입니다. |
| `.zip` | **zip** / **unzip** | 이종 OS(Windows/Linux 등) 간 호환성이 뛰어난 압축 형식입니다. |
| `.jar` | **jar** | Java 프로그램 아카이브 형식입니다 (Zip 알고리즘 기반). |
| `.alz` | **ALZip** | 이스트소프트 전용 압축 형식 (분할 압축 시 `.a00`, `.a01` 생성)입니다. |
| `.rar` | **WinRAR** | 높은 압축률의 상용 압축 형식입니다. |
| `.cab` | **Cabinet** | Microsoft 시스템 및 소프트웨어 설치용 압축 파일입니다. |
| `.Z` | **compress** | Unix 전통 압축 형식입니다. |
