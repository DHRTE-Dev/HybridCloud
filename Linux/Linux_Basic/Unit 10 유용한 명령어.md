## 1. cmp / diff 명령어

### cmp 명령어
- **개념**: 두 개의 파일을 **바이트(byte) 단위**로 비교하여 차이점이 시작되는 위치를 확인하는 명령어입니다. 파일 내용이 완전히 일치하면 아무런 출력을 반환하지 않습니다.
- **명령어 형식**: `cmp [옵션] <파일1> <파일2>`

| 옵션 | 설명 |
| :--- | :--- |
| **-l** | 두 파일의 차이점이 발생하는 모든 위치에 대해<br>10진수 바이트 위치와 틀린 바이트값(8진수)을 출력합니다. |
| **-s** | 차이점 메세지를 출력하지 않고<br>반환 코드(return code)만 제공합니다. |

### diff 명령어
- **개념**: 두 파일 또는 디렉토리 간의 **라인(line) 단위 차이점**을 비교하여 출력하는 명령어입니다. 디렉토리 비교 시 내부 파일의 변경 및 존재 여부까지 확인할 수 있습니다.
- **명령어 형식**: `diff [옵션] <파일1/디렉토리1> <파일2/디렉토리2>`

| 옵션 | 설명 |
| :--- | :--- |
| **-c** | 파일 이름, 날짜 및 변경된 라인의 앞뒤 문맥을 포함한<br>상세 컨텍스트(Context) 형식을 출력합니다. |
| **-i** | 알파벳 **대소문자를 구분하지 않고** 비교합니다. |
| **-r**, **--recursive** | 디렉토리 비교 시 모든 **하위 디렉토리까지 재귀적으로** 비교합니다. |
| **--brief** | 두 파일의 내용이 같은지 다른지의 여부만 간략히 확인합니다. |
| **-d** | 두 디렉토리 간의 차이점을 출력합니다. |
| **-H** | 대용량 파일 비교 시 속도를 최적화하여 비교합니다. |

### cmp / diff 주요 사용 예제
- **원본 및 백업 설정 파일 비교**:
  `diff server.xml server.xml.OLD`
- **디렉토리 이관(Migration) 결과 검증**:
  `diff -r /was1 /was2`

## 2. sort 명령어

### sort 명령어 개요 및 옵션
- **개념**: 텍스트 파일의 행을 정렬하여 표준 출력으로 나타내는 명령어입니다. 기본 정렬 기준은 **공백 문자(Space, Tab)** 구분, **오름차순**, **문자열** 기준입니다.
- **명령어 형식**: `sort [옵션] [파일이름]`

| 옵션 | 설명 |
| :--- | :--- |
| **-n** | 문자열이 아닌 **숫자 수치(Numeric value)** 크기 기준으로 정렬합니다. |
| **-r** | 정렬 결과를 **내림차순(Reverse)**으로 반전시킵니다. |
| **-k** | 정렬 기준이 되는 **필드 위치(Key POS)**를 지정합니다. |
| **-t** | 필드 구분자(Delimiter)를 직접 지정합니다. (예: `-t:`) |
| **-o** | 정렬된 결과를 지정된 파일에 저장합니다. |

### sort 주요 사용 예제
- **`/etc/passwd` 파일의 UID(3번째 필드) 기준 숫자 정렬**:
  `sort -t: -k 3 -n /etc/passwd`
- **디스크 사용량 내림차순 정렬**:
  `df -h | sort -k 4 -r`
- **`/var` 디렉토리 내 용량별 내림차순 정렬**:
  `du -sk /var/* | sort -nr | more`
- **사람이 읽기 쉬운 용량 단위 정렬**:
  `du -sh * | sort -hr | more`

## 3. file 명령어

### file 명령어 개요 및 주요 파일 유형
- **개념**: 파일의 헤더 및 데이터 구조(Magic Number 등)를 분석하여 **파일의 실제 종류(File Type)**를 판별하는 명령어입니다. 유닉스/리눅스 환경에서는 확장자가 강제되지 않으므로 확장자가 변경되거나 유실된 파일의 종류를 확인할 때 유용합니다.
- **명령어 형식**: `file [옵션] <파일 및 디렉토리...>`

| 판별 파일 유형 | 설명 |
| :--- | :--- |
| **ASCII text** | 일반 텍스트 파일 |
| **ELF 64-bit LSB shared object** | 리눅스/유닉스 64비트 실행 파일 (Binary) |
| **data** | 바이너리 데이터 파일 (예: `/var/log/wtmp`) |
| **Bourne-Again shell script** | BASH 셸 스크립트 실행 파일 |
| **script, ASCII text executable** | 파이썬 등 언어 스크립트 실행 파일 |
| **directory** | 디렉토리 |

### file 주요 사용 예제
- **단일 파일 및 디렉토리 형식 확인**:
  `file /etc/passwd`
- **현재 디렉토리 전체 항목 형식 확인**:
  `file *`
- **확장자가 유실되거나 잘못 지정된 파일의 원본 형식 확인**:
  `file all`
