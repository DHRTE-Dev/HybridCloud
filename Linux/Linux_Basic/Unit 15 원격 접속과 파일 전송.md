## 1. scp 명령어를 활용한 파일 전송

### scp 개요 및 특징
* **scp(Secure Copy)**는 **OpenSSH** 패키지에 기본 포함되어 있는 보안 파일 전송 클라이언트 프로그램입니다.
* **SSH(Secure Shell)** 프로토콜을 기반으로 작동하여 전송되는 데이터를 **암호화**합니다.
* 별도의 FTP 서버나 클라이언트 설치 없이 로컬과 원격 호스트 간, 또는 원격 호스트 상호 간 파일 및 디렉토리를 안전하게 복사할 수 있습니다.
* 기존의 암호화되지 않던 **rcp(Remote Copy)** 명령어를 대체합니다.

### scp 명령어 주요 옵션

| 옵션 | 설명 |
| --- | --- |
| **-r** | 디렉토리 및 하위 항목 전체를 재귀적으로 복사합니다. |
| **-P port** | 원격 호스트의 접속 **포트 번호**를 지정합니다.<br>(대문자 P를 사용하며, 소문자 -p는 파일 보존 옵션과 구분됨) |
| **-C** | 전송 시 데이터 **압축(Compression)**을 활성화합니다. |
| **-v** | **상세 출력(Verbose)** 모드를 활성화하여 연결, 인증, 설정 관련 디버깅 메시지를 출력합니다. |

### 초기 네트워크 프로토콜과의 비교

| 구분 | 초기 프로토콜 (보안 미적용) | 보안 강화 프로토콜 (SSH 기반) |
| --- | --- | --- |
| **원격 접속** | telnet, rlogin, rsh | **ssh** |
| **파일 전송** | ftp, rcp | **sftp**, **scp** |

### 자주 사용되는 사용 예제
* 로컬 파일 원격 서버로 전송: scp /test/server1.txt root@server2:/tmp
* 포트 번호 지정 전송: scp -P 22 /test/CentOS20 fedora@server2:/tmp
* 원격 서버 파일 로컬로 가져오기: scp fedora@server2:/home/fedora/testfile1 /test
* 원격 서버 디렉토리 전체 가져오기: scp -r server2:/test /tmp
* 로컬 디렉토리 원격 서버로 전송: scp -r /tmp/test server2:/tmp
* 원격 서버 간 파일 전송: scp server2:/test/passwd main:/tmp

## 2. sftp 명령어를 활용한 보안 파일 전송

### sftp 개요 및 특징
* **sftp(Secure File Transfer Protocol)**는 SSH 통신 채널을 사용하여 파일 전송을 수행하는 보안 인터랙티브 프로그램입니다.
* 기존 **FTP**가 사용자 계정 정보 및 전송 데이터를 평문으로 다루는 보안 취약점을 해결하기 위해 **암호화 통신**을 제공합니다.
* 접속 후 대화형 명령어 환경(Interactive Command Mode)을 통해 파일 및 디렉토리 관리 작업을 지원합니다.

### sftp 대화형 주요 명령어

| 명령어 | 설명 |
| --- | --- |
| **ls [path]** | 원격 시스템의 디렉토리 목록을 조회합니다.<br>(-1, -a, -l, -n, -r, -S, -t 옵션 지원) |
| **lls [path]** | **로컬** 시스템의 디렉토리 목록을 조회합니다. |
| **cd path** | 원격 시스템의 작업 디렉토리를 변경합니다. |
| **lcd path** | **로컬** 시스템의 작업 디렉토리를 변경합니다. |
| **pwd** | 원격 시스템의 현재 작업 디렉토리 경로를 표시합니다. |
| **lpwd** | **로컬** 시스템의 현재 작업 디렉토리 경로를 표시합니다. |
| **get [-P] remote [local]** | 원격 파일/디렉토리를 로컬로 **다운로드**합니다.<br>(-P 옵션 사용 시 권한 및 시간 정보 보존) |
| **mget remote-files** | 여러 개의 원격 파일을 일괄 다운로드합니다. |
| **put [-P] local [remote]** | 로컬 파일/디렉토리를 원격 시스템으로 **업로드**합니다.<br>(-P 옵션 사용 시 권한 및 시간 정보 보존) |
| **mput local-files** | 여러 개의 로컬 파일을 일괄 업로드합니다. |
| **mkdir path / lmkdir path** | 원격 / 로컬 시스템에 새로운 디렉토리를 생성합니다. |
| **rm path / rmdir path** | 원격 시스템의 파일 / 디렉토리를 삭제합니다. |
| **rename old new** | 원격 시스템의 파일 이름을 변경합니다. |
| **chmod / chown / chgrp** | 원격 파일의 **권한**, **소유자**, **그룹**을 변경합니다. |
| **! command** | sftp 세션을 유지한 상태로 **로컬 셸 명령어**를 실행합니다. |
| **bye / exit / quit** | sftp 대화형 세션을 종료하고 빠져나갑니다. |
| **help / ?** | 사용 가능한 대화형 명령어 도움말을 출력합니다. |

### 자주 사용되는 사용 예제
* sftp 서버 접속: sftp fedora@192.168.10.30
* 특정 원격 경로 지정 접속: sftp fedora@192.168.10.30:/home/fedora/*
* 대화형 모드 내 파일 업로드: sftp> put linuxfile20
* 대화형 모드 내 로컬 디렉토리 변경 후 파일 다운로드: sftp> lcd /root 후 sftp> mget file*
* 대화형 모드 내 로컬 셸 명령 실행: sftp> ! ls /root

## 3. ssh 명령어를 활용한 원격 접속 및 제어

### ssh 개요 및 원격 셸 실행
* **ssh(Secure Shell)**는 암호화되지 않은 **telnet**, **rsh**, **rlogin**을 대체하기 위해 개발된 보안 원격 접속 프로토콜 및 클라이언트 프로그램입니다.
* 안전한 원격 대화형 접속(Interactive Login) 외에도, 원격 서버에 **단일 명령어 및 스크립트(Remote Shell)**를 즉시 실행할 수 있습니다.

### ssh 명령어 주요 옵션

| 옵션 | 설명 |
| --- | --- |
| **-p port** | 접속할 원격 SSH **포트 번호**를 지정합니다.<br>(소문자 p 사용) |
| **-l login_name** | 원격 서버에 로그인할 **사용자 계정**을 지정합니다. |
| **-i identity_file** | **공개키 인증** 시 사용할 로컬 개인키 파일 경로를 지정합니다. |
| **-J destination** | 중계 서버를 거쳐 접속하는 **ProxyJump** 기능을 수행합니다. |
| **-X / -Y** | **X11 포워딩**을 활성화하여 원격 GUI 프로그램을 로컬 화면으로 전송합니다. |
| **-T** | 의사 터미널(**pseudo-tty**) 할당을 비활성화합니다.<br>(스크립트 내부 명령어 실행 시 활용) |

### 암호화 알고리즘 유형

| 암호화 유형 | 특징 | 대표 알고리즘 |
| --- | --- | --- |
| **대칭키 암호화** | 암호화와 복호화에 동일한 **비밀키(Secret Key)** 사용 | - 블록 암호: DES, 3DES, **AES**, SEED<br>- 스트림 암호: RC4 |
| **비대칭키 암호화** | **공개키(Public Key)**와 **개인키(Private Key)** 쌍 사용 | - 공개키 암호화: **RSA**<br>- 공개키 서명: **DSA** |
| **해시 알고리즘** | 단방향 암호화로 데이터 무결성 검증 및 비밀번호 저장에 활용 | MD5, **SHA** (Salt 키 결합) |

### 공개키 인증 방식 (Public Key Authentication)
* 원격 접속 시 매번 비밀번호를 입력하는 대신 **비대칭키 쌍**을 이용하여 자동으로 인증하는 방식입니다.
* **개인키(Private Key, id_rsa)**: 접속 요청 클라이언트 측(`~/.ssh/id_rsa`)에 보관하며 절대 외부에 유출되지 않아야 합니다.
* **공개키(Public Key, id_rsa.pub)**: 접속할 원격 서버 측(`~/.ssh/authorized_keys`)에 등록하여 서버가 클라이언트를 검증할 때 사용합니다.
* 자동화 스크립트 구축, Ansible과 같은 인프라 관리 도구, AWS EC2 등 클라우드 시스템 관리에 필수적으로 활용됩니다.

### 공개키 관리 명령어

| 명령어 | 설명 |
| --- | --- |
| **ssh-keygen** | 비대칭키 쌍(개인키/공개키)을 생성합니다.<br>(-t 옵션으로 rsa, dsa, ecdsa, ed25519 선택 가능) |
| **ssh-copy-id** | 생성된 공개키(`id_rsa.pub`)를 원격 서버의 `~/.ssh/authorized_keys`에 등록합니다.<br>(-i 옵션으로 특정 키 파일 지정) |

### 자주 사용되는 사용 예제
* 원격 서버 접속: ssh 192.168.10.30 또는 ssh root@192.168.10.30
* 특정 계정 및 포트 지정 접속: ssh -p 2222 fedora@192.168.10.30
* 경유지를 통한 원격 접속 (ProxyJump): ssh -J fedora@192.168.10.10 root@192.168.10.30
* 원격 서버 단일 명령어 실행: ssh server2 ls -l /tmp
* 원격 서버 다중 명령어 실행: ssh 192.168.10.30 'date; cal'
* 공개키 쌍 생성: ssh-keygen -t rsa
* 원격 서버로 공개키 배포: ssh-copy-id -i ~/.ssh/id_rsa.pub root@server2
